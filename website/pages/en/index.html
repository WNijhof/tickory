The to-do list you host yourself

Tickory is a to-do app for you, your family or a small team, running on your own server. Your data stays at home, the app keeps working without a connection, and you type a date the way you would say it.

Try the demo Install it yourself

Free software (AGPL-3.0) · one Docker container · no account with anyone else · the app itself is in Dutch for now

Why Tickory

  • Self-hosted

    One small Docker container on a mini PC, NAS or Raspberry Pi. No npm packages and no build step: there is little that can break.

  • Your data at home

    Everything lives in a single file on your own server. Nobody else reads along, and a backup is one command.

  • No subscription

    Tickory is free software. No monthly fee and no features behind a paywall.

  • Works offline

    The app keeps your tasks on your device. Without a connection you simply carry on; everything syncs by itself afterwards.

  • Together

    Everyone gets their own account and their own Inbox. Share a project with your housemates or colleagues and assign tasks to each other.

What you do with it

All screenshots below come from the app itself, with the sample data of the demo. The app is in Dutch for now; an English interface is in development.

Type it the way you say it

One line is enough. Loodgieter bellen morgen om 9 uur /Klusjes @bellen p1 (“call the plumber tomorrow at 9”) becomes a task for tomorrow 9:00, in the section Klusjes, with the label bellen and the highest priority. Below the field you see right away what was recognised.

Dates and recurrences are written in plain Dutch: over twee weken (in two weeks), voor Sinterklaas (before 5 December), elke tweede dinsdag (every second Tuesday), elke werkdag om 8:30 (every weekday at 8:30).

All dates and recurrences

Today and Upcoming

Vandaag (today) shows what is due today and what is overdue, from all your projects together. Binnenkort (upcoming) shows the next two weeks, day by day.

A recurring task you tick off moves on to its next date. Ticking off can be undone with one click.

More about the views

Together in one project

Share a project by typing the username of a housemate or colleague. Everyone sees and edits the same tasks and sections, and someone else's changes show up within a few seconds.

Assign a task to whoever is going to do it. Your Inbox and your labels remain yours alone.

Sharing and working together

Everything about a task in one place

Click a task for its details: description, date, deadline, priority, labels, project and section, and subtasks. In the date field you type the same plain language as when adding a task.

Projects, sections and subtasks

On your phone, even without signal

Tickory is a web app that you install as an app on your phone and computer. Without a connection it still opens and you can add and tick off tasks; as soon as the connection is back, everything goes to the server.

For that, your server has to be reachable over HTTPS. An Android app (APK) is in development.

Install in three steps

You need a computer that stays on, with Docker and docker compose. The image is available for ordinary PCs and NAS systems (amd64) and for a Raspberry Pi with a 64-bit system (arm64).

  1. Get the files

    git clone {{repo}}.git
cd tickory
cp .env.example .env

  2. Choose the first account

    Put a username and a password of at least 10 characters in .env. This account is created on the first start and is an administrator: you use it to create the other accounts in the app.

    TODO_ADMIN_USER=anna
TODO_ADMIN_PASSWORD=choose-a-long-password-here

  3. Start

    docker compose up -d
docker compose ps          # after a few seconds: (healthy)

    Then open http://127.0.0.1:8787 on the server itself and sign in.

This is what you start with that: the docker-compose.yml from the repository, shown here without its (Dutch) comments.

Set up like this, the container is only reachable from the server itself. For your phone and other devices you put HTTPS in front of it, which is possible without exposing anything to the internet. The guide explains how: installing, HTTPS, backup and updating.

What it cannot do (yet)

Tickory is young (version {{version}}). The core works and is tested, but much of what you know from the big to-do apps is still missing. Better to be honest up front than to disappoint you later.

In development

  • Reminders with a notification. The server can already store them, but the app has no screen for them yet and no notification is sent anywhere. Current state
  • An Android app (APK). Until it exists, you use the web app in your phone's browser. Current state
  • An English interface. The app is Dutch only for now, including the date language.

On the server, not yet in the app

  • Comments on tasks and projects
  • Filters (saved searches)
  • Sub-projects, favourites, archiving projects and sections
  • The duration of a task, and a board or calendar view

Missing entirely

  • Changing the order of tasks (dragging): a new task always goes to the end
  • Search
  • Managing labels: renaming, deleting, filtering by label
  • Attachments, import and export, an iCal feed, keyboard shortcuts, widgets, statistics, templates
  • Inviting by link or e-mail, and handing a project over to another owner
  • Signing up yourself or resetting your password by e-mail: an administrator does that

The name

A tick is a check mark, and also the tick of a clock. With a nod to the nursery rhyme “Hickory, dickory, dock”.

How it is built

A sync server and an installable web app in one container, on Node 26 with SQLite. The protocol is described in SPEC.md (in Dutch); the tests run on every change.
