Updating

You get a new version with two commands. Your data is in a Docker volume and is kept.

Installing a new version

Make a backup first. Then, in the directory with docker-compose.yml:

docker compose pull && docker compose up -d

Docker fetches the newest image and replaces the container. That takes a few seconds; during that time the apps on your devices carry on offline, and afterwards they sync by themselves.

  • Check with docker compose ps that the container is (healthy) again.
  • The web app on your devices fetches the new version in the background. It is active after you have opened the app once more after that.
  • If something changes in docker-compose.yml or .env.example in the repository, get those changes with git pull and compare them with your own .env.

Which version

The line image: {{image}}:latest always follows the newest released version. If you want to decide yourself when to switch, put a version number after it, for example {{image}}:{{version}}, and change that when you want to update. Released versions get three tags: the full number (0.2.0), the major and minor number (0.2) and latest.

Building it yourself

If you use build: . instead of the ready-made image, this is how you update:

git pull && docker compose up -d --build --pull always

Note: security updates of the underlying Node image only come in when the image is built again. So rebuild now and then, even when Tickory itself has not changed.

Upgrading from version 0.1

Version 0.1 was for one person and worked with a single fixed token (TODO_TOKEN). From 0.2 on, everyone has an account with a password.

  1. Make a backup of the database.
  2. Put the lines TODO_ADMIN_USER and TODO_ADMIN_PASSWORD in .env (see Installing). You can remove TODO_TOKEN; it is no longer used.
  3. Start the new version: docker compose pull && docker compose up -d.
  4. Sign in again on every device, now with the username and the password.

On the first start that account is created and takes over all existing data: projects, tasks, labels, filters and reminders, including your Inbox. After that you create accounts for the others in the app.

Back to a previous version

Put the previous version number after image: and run docker compose up -d. If the new version had already changed the database, also restore the backup you made beforehand; an older version cannot always read a newer database.
