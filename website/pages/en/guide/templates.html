Templates

A template is a project or a list of tasks you need more than once: moving house, a holiday, a new colleague. You pick the template, see what you get and create it in one go, with the dates counted from the day you choose.

Create a project from a template

  1. In the sidebar, next to the + under , click the button .
  2. Pick a template on the left. On the right you see what you get: the number of tasks and sections, which labels are new, and the first lines, with sections and subtasks indented.
  3. Give the project a name and choose Start on this day with a start date (quick choices: today, tomorrow or next week), or choose No dates. The preview shows the real dates straight away.
  4. Click . The project, with all its sections, tasks and subtasks, is there at once, even without a connection; the app opens the project.

If it is not what you wanted, click Undo in the message at the bottom: the project is removed again. Labels the template created for you stay.

Tasks from a template in an existing project

Choose in a project's menu, or click the same button in the window. You pick a template, the project and, if you like, the section for tasks that have no section in the template. The tasks go after what is already there. If the template has a section with the same name as one in the project (capitals do not matter), its tasks go in that section; other sections are created. Here too you can undo it.

Dates in a template

A template contains no fixed dates but relative days from the start date: day 0 is the start date itself, +3 days is three days later, +1 week a week later. A time (for example 09:00) stays with the task. If you choose No dates, the tasks get no date. Only a recurring task ("every Friday") keeps its recurrence and gets a date from today, on the first day that fits the recurrence; the app tells you so.

A task with a time gets the automatic reminder from › , just like a task you add yourself with a time.

Make your own template

  • From a project: in the project's menu choose . Give it a name and, if you like, a description. With the tick for dates, the dates become relative days (the earliest date becomes day 0); untick it to keep just the tasks.
  • From a task: open the task and click . The task goes with its subtasks and, if you want, the name of the section it is in.

Included: sections, open tasks and subtasks, with description, priority, labels (by name), duration and recurrence. Not included: completed tasks, deadlines, reminders, comments and assignments. So a template contains no names of people either.

A template holds at most 1,000 tasks and you can keep 100 templates. If a project is too large, the app says so before anything happens.

Sharing templates

Your templates are private: nobody sees them, not even in a shared project. To give someone one, share it as a file.

  • Export: pick a template and click . gives a file named tickory-template-….json; puts the text on the clipboard. It only contains sections and tasks.
  • Import: choose at the bottom of the templates window, or under › . Choose a file or paste the text. You first see what is in it and can change the name.
  • From Todoist: you can also import a Todoist CSV template (with the columns TYPE, CONTENT, INDENT, …). Tasks, sections, subtasks and priority come along. Dates and comments do not: a date there is free text in a language Tickory does not guess. The app tells you how many were left out.

A file from someone else is untrusted input. Tickory only reads it and checks it strictly (size, structure, lengths, counts); nothing is run or fetched from the internet, and text is never shown as markup. A file that is not right is refused with a message.

In the Android app the built-in browser cannot choose a file yet. Paste the text in the import window there, and use to share.

Managing templates

Under › you find all templates, with the kind next to each. You can look at one, share it, rename it or delete it (with confirmation), and import. A deleted template cannot be brought back; projects you made from it stay.

What is not possible yet

  • Sharing a template with another user of your server without a file.
  • Editing the content of a template in the app. To change one, make a project from it and save that as a template again.
  • Deadlines, reminders, comments and assignments in a template.
  • Taking over dates from a Todoist CSV.
