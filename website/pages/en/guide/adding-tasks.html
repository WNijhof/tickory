Adding tasks

At the top of every screen there is a single input field. Type a line, press Enter, and the task is in: with a date, project, section, labels, priority and reminders if you type them along.

The field says . The symbols below work in both languages of the app; only the dates and recurrences you type are recognised in Dutch for now, so the examples on this page are Dutch, with a translation.

While you type, the app shows below the field what it recognised. Whatever is not shown there simply stays in the name of the task.

The symbols at a glance

You typeMeaning
#ThuisPuts the task in the project Thuis.
/KeukenPuts the task in the section Keuken of that project.
@bellenGives the task the label bellen. A label that does not exist yet is created.
p1 to p4The priority; 1 is the highest. You can also type !!1 to !!4.
{vrijdag}A deadline: the final day, separate from the date on which you want to work on it.
morgen om 9 uurA date or recurrence in plain Dutch (here: tomorrow at 9). See Dates and recurrences.
!30mA reminder: 30 minutes before. Also !1u, !2d and !0 (at the time itself), or in plain Dutch between parentheses. See Reminders.
~Switches date recognition off, for when a word just happens to look like a date.

The order does not matter, and you do not have to use any of this: Melk kopen (buy milk) is a task too.

Examples

The examples assume Tuesday 17 November 2026, a project Thuis (home) with a section Keuken (kitchen), and an existing label bellen (calling).

You typeThat becomes
Tandarts bellen morgen om 9 uur #Thuis /Keuken @bellen p1 “Tandarts bellen” (call the dentist), Wednesday 18 November at 9:00, in Thuis / Keuken, label bellen, priority 1
Pay rent 31-12 p1 “Pay rent”, 31 December, priority 1 (this is the example in the input field of the English interface; a date like 31-12 works in any language)
Aangifte doen {31-12} !!2 “Aangifte doen” (file the tax return), no date, with deadline 31 December and priority 2
Offerte nakijken donderdag {vrijdag} p2 “Offerte nakijken” (check the quote), to do on Thursday, to be finished by Friday
Melk kopen @boodschappen “Melk kopen” with the new label boodschappen (the preview below the field adds “(new)”)
Oud papier elke tweede dinsdag #thuis “Oud papier” (waste paper) in Thuis, every second Tuesday of the month; the first time on 8 December
Mail naar jan@voorbeeld.nl sturen Stays exactly like that: a symbol only counts at the start of a word, so an e-mail address is not a label

Where the task ends up

  • If you are in a project, the task goes into that project.
  • If you are in , the task goes into your Inbox and gets today's date, unless you type a different date yourself.
  • If you are in , the task goes into your Inbox, without a date if you do not type one.
  • With #project you can always pick another project yourself.

A new task goes to the bottom of the list. Changing the order of tasks is not possible yet.

The Add task window

The Add task window, with the same line as the input field and below it what was recognised.

Choose in the sidebar, or the button with the same name under a section or in , or press q. A larger window opens with the same input: the line with #, /, @, p1, !30m and a date, a field for a description, the preview of what was recognised, and a drop-down list for the project. Choose or press Enter in the line.

  • The project is preset to the project you are in; under a section also to that section. From it is your Inbox, with today's date. Choose another project in the drop-down list, or type #project in the line (that wins).
  • You type a description in the second field; it then appears in grey under the name of the task.

Speaking a task

If your device has speech recognition, the Add task window has a microphone button next to the input field. Tap it, say for example "Call the dentist tomorrow at nine" and the recognised text lands in the field, where the usual recognition of date, project and priority picks it up. Nothing is created until you tap Add, so you can check it first.

  • In the Android app the Android speech screen opens. Your phone decides which speech service that is (and whether it works offline); Tickory only receives the recognised text and has no microphone access of its own.
  • In a browser it works where the browser has speech recognition (Chrome, Edge, Safari). Note: Chrome and Edge send the recording to the browser maker's speech service; that is not Tickory. Firefox does not have it, so you see no button there.
  • The language is that of the interface (Dutch or English).

The parts one by one

Project: #

Type # followed by the name of an existing project. Capitals do not matter, and a name with spaces works too: with #Vakantie Texel the longest name that fits wins. A project that does not exist is not created; the text then stays in the name of the task. You create a new project with the + in the sidebar.

Section: /

Type / followed by the name of a section in the chosen project. If the section does not exist in that project, the text stays where it is. A word like en/of (and/or) is left alone.

Label: @

Type @ followed by the name of the label. A label name here consists of letters, digits, - and _, without spaces. Capitals and accents do not matter: @ÉÉN is the same label as @één. You can put several labels on one line. Labels are personal; see what stays personal.

Priority: p1 to p4

p1 is the highest priority, p4 means “none” and is also what a task gets when you type nothing. You can tell the priority from the colour of the circle in front of the task: red for P1, orange for P2, blue for P3.

Deadline: { }

A task has a date (when do you want to work on it) and can also have a deadline (when must it be finished at the latest). You put the deadline between braces: {31-12}, {vrijdag}, {voor Sinterklaas}. Between the braces you put a single day: a recurrence is not possible there, and a time is ignored.

Reminder: !

An exclamation mark with a number of minutes, hours or days before gives the task a reminder: !30m, !1u (u is the Dutch uur, hour), !2d; !0 is at the time itself. That works on a task with a time. If you put no reminder in the line, a task with a time gets the automatic reminder by itself (30 minutes before by default). Everything about it is under Reminders.

Switching date recognition off: ~

Sometimes a word looks like a date when it is not one. Type a ~ in that case:

You typeThat becomes
~Bellen morgen“Bellen morgen”, without a date: a ~ at the start applies to the whole line
Vergadering ~elke maandag voorbereiden“Vergadering elke maandag voorbereiden”, without a recurrence: a ~ before a word applies to the date that starts there

Often you will not need it: the app deliberately leaves alone whatever is not clearly a date. See what deliberately does not become a date.

After that: filling in the task

Click a task to edit it. There you add a description and subtasks, move the task to another project or section, and assign it to someone. See The task window.
