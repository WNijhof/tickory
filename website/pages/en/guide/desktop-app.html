Desktop app for Windows

The desktop app shows the web app of your own server in its own window, just like the Todoist desktop app does with todoist.com. On top of that you get what a browser cannot do: a tray icon, shortcuts that work everywhere, a dot on the taskbar, and regular Windows notifications for your reminders, for collaboration and for your daily overview.

New

The installer (Tickory-Setup-….exe) is attached to every version from 0.10.0 on the releases page on GitHub. It is not signed with a certificate yet: Windows SmartScreen may warn the first time. Choose More info and Run anyway.

Installing and connecting

  1. Download Tickory-Setup-….exe from the releases page and run it. You can choose where the program goes; it is added to the Start menu and the desktop.
  2. On the first start Tickory asks for the address of your server, for example tasks.example.com. Outside your own network it has to be https.
  3. Then sign in as in the browser. You stay signed in, also after a restart.

The tray

The icon at the bottom right of the taskbar opens a menu with Add task, Show Tickory, today's tasks (with a dot in the priority colour; click to open the task), the fixed views (Inbox, Today, Upcoming, Completed, Notes), Settings, Keep running in the tray and Quit Tickory. When you close the window, Tickory keeps running in the tray, so reminders and shortcuts keep working; turn that off with Keep running in the tray.

Shortcuts

  • Ctrl+Space, anywhere in Windows: a small Add task window at the top of the screen. Type the task as always (Dentist tomorrow 9am p1), add it, and the window goes away again.
  • Win+Alt+S: show or hide Tickory.

Both can be changed or turned off under Settings (in the File menu or the tray). If a shortcut is already used by another program, Tickory says so.

Notifications

The desktop app shows Windows notifications itself. Like the web app, it hears from your server right away when something changes; to be safe it also fetches the latest state every five minutes. This works while Tickory is running, also when the window is closed and Tickory sits in the tray.

  • Reminders on tasks, with the buttons Complete and Snooze (as long as you chose under Settings › Reminders). Snoozing only applies on this computer, as on Android. Clicking the notification opens the task.
  • Reminders on notes, with the button Open.
  • Collaboration notifications: someone assigned you a task, commented, mentioned you, added you to a project or shared a note with you. You choose which kinds you get under Settings › Notifications, as for the browser and the Android app. Clicking opens the task, project or note and marks the notification as read. If you are busy in Tickory itself at that moment, no Windows notification is added: you already see it in the app. If you read it elsewhere, it also disappears from Windows.
  • Morning overview and evening review at the times you choose under Settings › Notifications, with numbers only. Clicking opens Today.

A reminder you just missed (the computer was asleep) still comes if it is not older than a quarter of an hour. Nothing comes in? Under Settings › Reminders, at Notifications on this device, you send a test notification and open the Windows settings (are notifications for Tickory on, and is Do not disturb off?).

More

  • A dot on the taskbar when tasks are due today (or overdue).
  • Menu: File (Add task, New window, Settings, Other server, Clear application data), Edit, View (back, forward, reload, zoom, full screen), Window (Float on top) and Help (guide, what's new, check for updates).
  • Start with Windows, optionally straight into the tray: under Settings.
  • Theme: same as Windows, light or dark, and an accent colour, as in the Android app. Choose it in Tickory under Settings › Theme or in the app's own Settings; it takes effect at once in all windows (including the Add task window) and in the title bar and menus.
  • Updates come by themselves: the app checks GitHub at start, downloads a new version in the background and then asks you to restart.
  • Notes are simply in the app, as in the browser.

What does not work (yet)

  • Voice in the Add task window: Electron, which the app runs on, has no speech service.
  • Notifications while Tickory is fully closed (so not in the tray either).
  • A version for macOS or Linux; the code is prepared for it.
