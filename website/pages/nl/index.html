De takenlijst die je zelf host

Tickory is een takenapp voor jezelf, je gezin of een klein team, op je eigen server. Je gegevens blijven thuis, de app werkt ook zonder verbinding, en een datum typ je zoals je hem zegt.

Vrije software (AGPL-3.0) · één Docker-container · geen account bij een ander nodig

Waarom Tickory

  • Zelf hosten

    Eén kleine Docker-container op een mini-pc, NAS of Raspberry Pi. Geen npm-pakketten en geen build-stap: er is weinig dat stuk kan gaan.

  • Je gegevens thuis

    Alles staat in één bestand op je eigen server. Niemand leest mee, en een back-up is één commando.

  • Geen abonnement

    Tickory is vrije software. Geen maandbedrag en geen functies achter een betaalmuur.

  • Werkt offline

    De app bewaart je taken op je apparaat. Zonder verbinding werk je gewoon door; daarna wordt alles vanzelf bijgewerkt.

  • Samen

    Iedereen een eigen account en een eigen Inbox. Deel een project met je huisgenoten of collega's en wijs taken aan elkaar toe.

Op je telefoon, ook zonder bereik

Tickory is een web-app die je op je telefoon en computer als app installeert. Zonder verbinding opent hij gewoon en kun je taken toevoegen en afvinken; zodra er weer verbinding is, gaat alles naar de server.

Daarvoor moet je server via HTTPS bereikbaar zijn. Een Android-app (APK) is in ontwikkeling.

Installeren in drie stappen

Je hebt een computer nodig die aan blijft staan, met Docker en docker compose. De image is er voor gewone pc's en NAS-systemen (amd64) en voor een Raspberry Pi met een 64-bit systeem (arm64).

  1. Haal de bestanden op

    git clone {{repo}}.git
cd tickory
cp .env.example .env

  2. Kies het eerste account

    Zet in .env een gebruikersnaam en een wachtwoord van minimaal 10 tekens. Dit account wordt bij de eerste start aangemaakt en is beheerder: daarmee maak je in de app de andere accounts aan.

    TODO_ADMIN_USER=anna
TODO_ADMIN_PASSWORD=kies-hier-een-lang-wachtwoord

  3. Start

    docker compose up -d
docker compose ps          # na enkele seconden: (healthy)

    Open daarna http://127.0.0.1:8787 op de server zelf en log in.

Dit is wat je daarmee start: het docker-compose.yml uit de repo, hier zonder de toelichting.

De container is zo alleen bereikbaar vanaf de server zelf. Voor je telefoon en andere apparaten zet je er HTTPS voor; dat kan zonder iets openbaar te maken. In de handleiding staat hoe: installeren, HTTPS, back-up en bijwerken.

Wat het (nog) niet kan

Tickory is jong (versie {{version}}). De kern werkt en is getest, maar veel van wat je van grote takenapps kent, ontbreekt nog. Liever eerlijk vooraf dan een teleurstelling achteraf.

In ontwikkeling

  • Herinneringen met een melding. De server kan ze al opslaan, maar de app heeft er nog geen scherm voor en er wordt nergens een melding verstuurd. Stand van zaken
  • Een Android-app (APK). Tot die er is, gebruik je de web-app in de browser van je telefoon. Stand van zaken
  • Een Engelse interface. De app is nu alleen Nederlands, ook de datumtaal.

Staat op de server, nog niet in de app

  • Opmerkingen bij taken en projecten
  • Filters (opgeslagen zoekopdrachten)
  • Subprojecten, favorieten, archiveren van projecten en secties
  • De duur van een taak, en een bord- of kalenderweergave

Ontbreekt helemaal

  • De volgorde van taken wijzigen (slepen): een nieuwe taak komt altijd achteraan
  • Zoeken
  • Labels beheren: hernoemen, verwijderen, op een label filteren
  • Bijlagen, import en export, een iCal-feed, sneltoetsen, widgets, statistieken, sjablonen
  • Uitnodigen via een link of e-mail, en een project overdragen aan een andere eigenaar
  • Zelf een account aanmaken of je wachtwoord per e-mail herstellen: dat doet een beheerder

De naam

Een tick is een vinkje, en ook de tik van de klok. Met een knipoog naar het Engelse rijmpje “Hickory, dickory, dock”.

Hoe het gebouwd is

Een sync-server en een installeerbare web-app in één container, op Node 26 met SQLite. Het protocol is beschreven in SPEC.md; de tests draaien bij elke wijziging.
