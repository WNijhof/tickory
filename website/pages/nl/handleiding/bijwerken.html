Bijwerken

Een nieuwe versie haal je op met twee opdrachten. Je gegevens staan in een Docker-volume en blijven daarbij bewaard.

Een nieuwe versie installeren

Maak eerst een back-up. Daarna, in de map met docker-compose.yml:

docker compose pull && docker compose up -d

Docker haalt de nieuwste image op en vervangt de container. Dat duurt enkele seconden; in die tijd werken de apps op je apparaten offline door en daarna werken ze zichzelf bij.

  • Controleer met docker compose ps dat de container weer (healthy) is.
  • De web-app op je apparaten haalt de nieuwe versie op de achtergrond op. Die is actief nadat je de app daarna nog een keer hebt geopend.
  • Verandert er iets aan docker-compose.yml of .env.example in de repo, haal die wijzigingen dan op met git pull en vergelijk ze met je eigen .env.

Welke versie

De regel image: {{image}}:latest volgt steeds de nieuwste uitgebrachte versie. Wil je zelf bepalen wanneer je overstapt, zet er dan een versienummer achter, bijvoorbeeld {{image}}:{{version}}, en pas dat aan als je wilt bijwerken. Uitgebrachte versies krijgen drie tags: het volledige nummer (0.2.0), het hoofd- en subnummer (0.2) en latest.

Zelf bouwen

Gebruik je build: . in plaats van de kant-en-klare image, dan werk je zo bij:

git pull && docker compose up -d --build --pull always

Let op: beveiligingsupdates van de onderliggende Node-image komen pas binnen als de image opnieuw wordt gebouwd. Bouw dus af en toe opnieuw, ook als Tickory zelf niet is veranderd.

Upgraden vanaf versie 0.1

Versie 0.1 was voor één persoon en werkte met één vast token (TODO_TOKEN). Vanaf 0.2 heeft iedereen een account met een wachtwoord.

  1. Maak een back-up van de database.
  2. Zet in .env de regels TODO_ADMIN_USER en TODO_ADMIN_PASSWORD (zie Installeren). TODO_TOKEN mag je weghalen; het wordt niet meer gebruikt.
  3. Start de nieuwe versie: docker compose pull && docker compose up -d.
  4. Log op elk apparaat opnieuw in, nu met de gebruikersnaam en het wachtwoord.

Bij de eerste start wordt dat account aangemaakt en neemt het alle bestaande gegevens over: projecten, taken, labels, filters en herinneringen, inclusief je Inbox. Daarna maak je in de app accounts aan voor de anderen.

Terug naar een vorige versie

Zet het vorige versienummer achter image: en draai docker compose up -d. Had de nieuwe versie de database al aangepast, zet dan ook de back-up terug die je vooraf maakte; een oudere versie kan een nieuwere database niet altijd lezen.
